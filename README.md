# 拾译 · Shiyi

独立桌面划词翻译器，目标是在选中文字时给出贴合当前场景的翻译。当前已提供 macOS 原生菜单栏版本，Windows 版计划在同一个仓库内继续开发。

| 平台 | 当前状态 | 代码入口 |
| --- | --- | --- |
| macOS 15+ | v0.2.0 预览版 | `Sources/Shiyi` |
| Windows | 计划中，尚无可执行程序 | [platforms/windows](platforms/windows/README.md) |

在 macOS 中按 **⌥⌘T** 唤出常驻置顶浮窗，之后划词会在固定位置更新译文。译文区域鼠标穿透，右上角的固定操作点用于展开、收起和内容操作。

系统翻译使用 macOS Translation；需要结合句段判断词义时，可配置自己的 AI 服务。当前为本机开发版，最低要求 **macOS 15**，构建需要提供 macOS 15 或更新 SDK 的完整 Xcode。项目没有第三方依赖。

## 下载与安装

从 [GitHub Releases](https://github.com/vMarkEvanv/shiyi/releases) 下载对应架构的 macOS ZIP，解压后将“拾译.app”放入“应用程序”文件夹，再授权辅助功能。`arm64` 适用于 Apple Silicon，`x64` 适用于 Intel；首个上传的安装包为 `arm64`。

这是未经 Apple 公证的预览版本。首次打开可能需要在系统“隐私与安全性”中按提示确认启动，不需要关闭系统安全保护。Release 包默认使用临时签名，不包含本机的开发签名证书；本地构建则优先保留稳定的开发签名。

每个安装包附有 `.sha256` 文件，可在解压前校验：

```sh
shasum -a 256 -c Shiyi-v0.2.0-macOS-arm64.sha256
```

## 构建与打开

在项目目录执行：

```sh
./scripts/build-app.sh
open "build/拾译.app"
```

构建脚本也可以使用绝对路径从其他目录运行。它优先使用外部 `DEVELOPER_DIR`，其次使用当前选择的完整 Xcode，最后检测 `/Applications/Xcode.app`。如果需要指定 Xcode：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/build-app.sh
```

可执行文件、图标和应用包生成在项目的 `build/`；编译缓存放在 `.build/`。构建前先退出拾译，脚本会拒绝覆盖正在运行的应用。脚本优先使用本机已有的 Apple Development 或 Developer ID 签名证书，也可通过 `SHIYI_SIGNING_IDENTITY` 指定证书；没有证书时回退到 ad-hoc 临时签名。脚本不安装、不启动应用，不修改登录项。产物未经 Apple 公证，适合本机开发验证，尚不适合作为正式发行包分发。

打包 Release ZIP（不覆盖本地应用）：

```sh
./scripts/package-release.sh
```

安装包及校验文件输出到 `dist/`，不提交到 Git 历史，通过 GitHub Release 分发。打包过程使用应用自身的版本号和二进制架构，不依赖文件名猜测。若需要自己的发布签名，可设置 `SHIYI_RELEASE_SIGNING_IDENTITY`；默认使用临时签名。

## 开始使用

1. 打开应用后会显示主窗口；关闭窗口后，也能从屏幕顶部菜单栏再次打开。
2. 按应用提示，在“系统设置 → 隐私与安全性 → 辅助功能”中允许拾译读取选中文字。授权后若读取仍失败，退出并重新打开拾译。
3. 按 **Option + Command + T（⌥⌘T）** 唤出浮窗，之后它保持置顶，不跟随鼠标、不因切换应用或外部点击而关闭。再次按快捷键隐藏浮窗，再按则重新显示并翻译当前选区。
4. 自动模式默认开启，在浮窗显示时，鼠标选区稳定后会读取并翻译；隐藏浮窗时暂停自动取词。也支持 Shift 配合方向键扩选后翻译。自动模式开关在拾译主窗口的偏好设置里。
5. 在主窗口或偏好设置中选择“原文语言 → 目标语言”，默认英语 → 简体中文，支持一键交换并自动保存。划词和手动输入共用此语言对，两个引擎都不会自动切换原文语言。原文语言与目标语言相同时直接保留原文，不调用翻译引擎。

## 常驻浮窗

- 浮窗的译文区始终允许鼠标穿透：点击、拖动与滚动作用于下面的软件。主窗口手动翻译不会自行唤出浮窗。
- 右上角圆形操作点是唯一的常驻鼠标入口，不随展开或收起移动，也不随译文区透明度变淡。左键展开或收起，按住拖动可移动浮窗并保存位置；右键菜单提供复制、重试及向上/向下浏览；在操作点上滚动也可浏览长内容。
- Esc 仅收起展开内容，不隐藏浮窗。隐藏操作在拾译主窗口完成，不在浮窗上放关闭、固定、设置或应用排除按钮。
- 在主窗口的“偏好设置 → 常驻浮窗”里调整透明度（0%–80%）、显示屏幕、水平/垂直位置及唤出快捷键，设置自动保存并即时生效。展开所需空间会预留在屏幕内，避免操作点移动或内容超出可见区域。
- 默认快捷键为 ⌥⌘T，也可选 ⌃⌥T 或 ⌃⇧T。冲突时保留原来可用的快捷键并提示；主窗口“显示浮窗”按钮始终可用。
- 断开已选择的显示器时暂用主屏幕，重新连接后恢复；切换桌面和普通全屏应用时保持显示。操作系统的权限或安全界面可能覆盖浮窗。
- 系统翻译首次下载语言包时，需要响应 macOS 自带的语言下载对话框；完成或取消后自动恢复译文区穿透。

辅助功能权限用于获取选区和可用的附近文字。支持程度由目标软件决定；画布、自绘控件、扫描 PDF、部分网页和编辑器可能不提供选区或上下文。无法读取时，可在拾译的输入窗口手动粘贴文本。当前版本不使用截图 OCR，也不以模拟复制替换剪贴板内容。这里不保证任何特定第三方应用的兼容性。

如果系统设置中的开关已打开，拾译仍显示“等待辅助功能授权”，尤其是在临时签名版本重建后：先退出拾译，在辅助功能列表中移除旧的拾译记录，再用列表的“+”重新添加当前 `build/拾译.app` 并开启。仅关闭再打开旧记录的开关，可能继续使用旧签名要求。重新启动拾译后，应显示“辅助功能已授权”。使用同一个有效开发证书签名可保持版本之间的应用身份。[Apple 对临时签名与应用身份的说明](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)

## 翻译引擎与数据

**系统引擎**使用 Apple Translation，首次使用可能需要系统下载对应语言资源。它翻译选中文字，不进行基于周围段落的 AI 语境推理；语言可用性取决于 macOS。

**AI 引擎**需要自行配置兼容 Chat Completions 的服务地址、模型名和 API Key。密钥保存在 macOS Keychain；服务地址与模型名保存在本机设置中。服务费用和数据处理由配置的服务商决定。使用自己的地址时，请确认它是你信任的服务。

AI 请求以选中文字为翻译目标，开启上下文时会附带选区附近最多 4,000 字符、应用名和可用文档标题，不发送整份文档。可在设置中关闭上下文，此时也不发送应用名或标题。无法读取上下文时，仅参考选中文字、场景偏好和开启的可用来源信息。应用不保存翻译历史；设置和密钥会持续保留，直至用户修改或删除。翻译内容显示在当前窗口中，不建立本地词库。

单次选中文字最多 5,000 字。密码框会跳过，钥匙串访问应用默认被排除。展开或收起浮窗不会暂停更新译文；需要暂停时，在主窗口关闭自动划词，或隐藏浮窗。

## 验证

运行项目测试：

```sh
./scripts/test.sh
```

单元测试不替代权限与跨应用手测。实际使用前，应分别检查选区读取、上下文范围、快捷键、自动模式以及翻译服务响应。授权由 macOS 管理；开发期间重建或移动应用可能需要重新检查辅助功能授权。

`.github/workflows/macos.yml` 在主分支推送和 Pull Request 时运行测试、构建、打包，产物可从对应 Actions 任务下载。此流程不会自动发布 Release，也不需要上传开发证书或 API Key。

## 后续 Windows 版

Windows 应用放在 `platforms/windows/`，平台 UI、选区读取、凭据存储和系统翻译引擎分别实现。AI 模式的输入输出和取消规则参考 [翻译数据约定](docs/translation-protocol.md)。保留现有 macOS 工程路径，Windows 版完成后增加独立构建任务与安装包。

已知限制：部分应用不提供辅助功能选区；原文语言需要与你选中的文字相符。当前没有 OCR、整篇翻译、生词本或自动更新。

### WPS 与复制翻译

- WPS 的文字/PDF 选区优先通过辅助功能读取；不可读取时，尝试复制选区并恢复原剪贴板。需保持 WPS 在前台，扫描图片 PDF 仍需要 OCR。
- 在任何可复制文字的软件里，按 **⌘C**，松开 ⌘，**3 秒内单独按 T**，翻译刚复制的文本并显示浮窗。T 会作为触发键，不写入文档。
- 其他按键或鼠标点击会取消等待；超时后 T 恢复正常。复制内容必须有更新，最长 5,000 字；复制翻译不额外读取上下文。
- 在主窗口“偏好设置 → 阅读方式”中可关闭“复制后按 T 翻译”。
